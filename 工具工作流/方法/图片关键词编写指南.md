# 图片关键词编写指南（精简版）

## 核心方法 · 三步逻辑

按顺序生成关键词，缺一步就会漏或者偏：

**① 客观描述** — 画面里真实看得见的东西
- 地点：洲/国/省/市/景点正式名+俗称，无辨识度就不写
- 时间：季节 + 一天时段（不得内部冲突）
- 主体：人物（年龄/关系/动作）、物体、动植物
- 环境：地貌、气候、色调
- 扫描技巧：**上-中-下 / 左-中-右 / 远-中-近** 各扫一遍

**② 概念情绪** — 画面能自然引发的意境
- 由客观元素反推出的情绪/概念，例如 冬季→寒冷；帐篷→露营/探险；冷蓝绿→科技/未来
- **必须能被画面元素支撑**，凭空写"幸福/爱/美好"这类抽象词 = 过度联想

**③ 创作技法**
- 景别（全景/远景/中景/近景/特写）+ 视角（俯视/仰视/航拍）+ 构图（横/竖）
- 特殊技法：长曝光、剪影、HDR、堆栈
- 插画额外：矢量/位图 + 风格（水彩/油画/水墨/扁平/2.5D/低多边形/国风）

---

## 硬规则（每次生成后必自检）

| 字段 | 规则 |
|---|---|
| 文件名 | 保留原名 + 扩展名 |
| 标题 | ≤ 20 字，客观描述画面，不加情绪 |
| 关键字 | 5~50 个，英文逗号分隔 |
| 核心关键词 | ≤ 2 个，**必须从关键字列里选**，不能新造 |
| 类型 | 三选一：照片 / 插画 / AIGC |
| 分类 | ≤ 2 个，仅限 25 种清单 |
| AI 工具 | 仅当类型=AIGC 时填，≤15 字；照片/插画留空 |

**25 种分类固定清单**（不得扩展）：
自然, 建筑, 节日, 商务, 医疗, 科技, 教育, 食物, 物体, 人物, 运动, 动物, 艺术, 工业, 标识, 背景, 户外, 运输, 科学, 宗教, 时尚, 抽象, 复古, 室内, 其它

---

## 四条最容易踩的坑（重点防）

1. **过度联想** — 画面里没出现的元素不写。看起来"应该在"的东西也不写（例：拍故宫不写"皇帝"，拍冬天不写"寒冷"除非有相关动作）。
2. **词组不拆** — "北京故宫" → `北京, 故宫`；"蓝天白云" → `蓝天, 白云`；"果蔬" → `水果, 蔬菜`。
3. **互斥共存** — 白天+黑夜 / 黎明+黄昏 / 春+夏 / 北京+纽约 / 狗不理包子+小笼包，不能同时出现。
4. **禁忌类词汇** — 网络用语（打卡/网红/ins风）、口语（老妈/挺好）、成语（兴高采烈）、诗歌、方言、拍摄设备型号（佳能/5D4）、主观词（我国/爷爷家的）、错别字。

---

## 类型判定原则

- **有画面且是拍摄** → 照片
- **矢量或明显绘画风格** → 插画
- **AI 生成图像** → AIGC（必须填 AI 工具）
- 无法确定 → **询问用户**，不猜

---

## 输出格式

表头顺序（不可变）：
```
图片文件名 | 图片标题 | 图片关键字 | 核心关键词 | 图片类型 | 图片分类 | AI工具
```

批量交付时用 openpyxl 生成 xlsx（表头填色 305496 白字，列宽约 32/24/56/18/10/14/12）。

## 快速自检（生成后过一遍）

- [ ] 无互斥词共存
- [ ] 无词组（都是单词）
- [ ] 无禁忌词
- [ ] 核心关键词都出自关键字列
- [ ] 分类 ≤2 且在 25 种内
- [ ] AIGC 才填 AI 工具
