# B站主动观看工作流

更新：2026-11-08。

让收藏、稍后再看、关注UP的更新成为日常入口，减少不想看的推荐干扰；同时保留可检索的观看历史。核心动作是：先看一条自己选过的内容，再决定是否继续。

## 工具组合

| 工具 | 用途 | 官方来源 |
|---|---|---|
| Tampermonkey（篡改猴） | 运行Gate用户脚本 | [Chrome商店](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) |
| Bilibili-Gate | 改造首页，集中浏览收藏、待看和关注动态，按规则过滤 | [GitHub](https://github.com/magicdawn/Bilibili-Gate) · [安装页](https://greasyfork.org/zh-CN/scripts/443530) |
| Bilibili 无限历史记录 | 定期同步历史，本地长期保存、检索和备份 | [GitHub](https://github.com/mundane799699/bilibili-history-wxt) · [Chrome商店](https://chromewebstore.google.com/detail/cfloggaggkeocfoflejkmhdhbehjojga) |

两项功能分别由Gate和历史扩展承担，不是一体化工作台。本文以Mac上的Chrome为例，其他浏览器先核对各项目当前支持情况。

## 安装和恢复

1. 安装篡改猴及无限历史记录。已安装时直接检查版本、启用状态与已有设置，保留个人规则和本地历史。
2. 在Chrome的篡改猴扩展详情页开启“允许用户脚本”；若旧界面提示开发者模式，按其提示操作。
3. 从上面的官方安装页安装Bilibili-Gate，在篡改猴管理面板确认脚本开关开启。
4. 登录B站，再打开 [Gate入口](https://www.bilibili.com/?gate=1)。出现Gate界面后，按 **Shift＋逗号** 打开设置。
5. 若已有自定义Gate设置，先导出备份。通过**整套设置的“导入”**选择本目录的 [gate-active-viewing.json](gate-active-viewing.json)，不要选“内容过滤”分区内的独立导入。
6. 导入并刷新后，首次进入 [收藏入口](https://www.bilibili.com/?gate=1&gate-tab=fav)，再打开普通B站首页，检查当前标签是否保持为收藏。
7. 从浏览器工具栏打开无限历史记录，执行首次全量同步，检索一条最近看过的视频。收藏同步如需单独触发，在扩展里操作并验证。

首次收藏入口会将当前标签切到收藏。**只把收藏排第一，并不会改变脚本原本选中的推荐标签。** 配置隐藏推荐入口后，仍应检查首次选择是否正确。

## 预设内容

- 可见入口：**收藏 → 稍后再看 → 动态 → 历史**。动态展示关注UP的更新，支持使用已有关注分组。
- 隐藏App推荐、PC推荐、热门、直播等标签，减少被动进入推荐流的机会。
- 待看按添加时间从旧到新，关闭其连续播放和视频卡片自动预览。
- 保留全部收藏夹；标题过滤仅包含“领券下单、直播间抢购、限时秒杀、点击小黄车”四个明确带货用语。推荐过滤对已关注内容保留豁免。
- 不按播放量、弹幕数或时长筛掉内容，避免误挡新发布、小众技术或简短但有用的视频。未预设屏蔽任何UP。
- 关闭Gate设置备份到B站文章草稿的选项。这个配置文件不管理历史扩展的云同步开关。

预设导入采用Gate的部分设置格式；未列出的设置保留。视频播放器自身的自动播放和相关推荐需要另行检查，不能将这里的待看连续播放开关理解为全站自动播放总开关。

## 日常使用

先从收藏或待看挑一条；想追关注UP的更新时再切动态。关注分组可以按“技术学习、求职、兴趣”等个人需要维护，不必为了整理而重分所有收藏。

确实不想看的内容，逐步添加具体标题词或UP过滤。优先调整自己打开内容的路径，不追求一次屏蔽全部干扰。需要重新浏览推荐时，可在Gate设置里恢复相应标签。

## 仍显示普通B站首页时

查询参数只是已经运行的Gate脚本识别的入口，单独打开链接不会安装脚本。

按顺序检查：

1. 当前浏览器和用户配置中是否装了篡改猴，扩展是否启用。
2. Chrome是否允许篡改猴运行用户脚本，是否授予B站站点访问权限。
3. 篡改猴管理面板里Gate是否存在且开启。
4. 安装后强制刷新B站（Mac为 **⌘⇧R**），或重新打开标签页。
5. 是否有其他首页改造扩展冲突，或脚本依赖因网络原因加载失败。按单个变量排查，先备份设置，再调整冲突项。

Gate出现“收藏、稍后再看、动态”等入口，且Shift＋逗号能打开设置，才算页面接管成功。随后再导入预设与核验历史同步。

## 能力边界与数据

- 本地过滤控制网页显示内容，不等于精确修改B站推荐算法；这些关键词也不会自动注入你想看的主题。
- 标题过滤无法识别全部广告，更不能去掉视频内的口播植入。
- 收藏和关注入口依赖登录；未登录时Gate可能仍显示推荐。
- 历史扩展默认每30分钟同步，并非逐秒计时。浏览器关闭时不能依靠它持续同步；首次只能抓到B站接口仍提供的历史。
- 历史默认存浏览器本地库，不等于自动备份，也不能保证重装浏览器后仍在。按需导出备份到本地。
- 可选AI搜索会将历史标题、UP、观看时间等发到配置的模型服务；WebDAV、云同步也会外发数据。仅需本地记录时不必启用。
- 本仓库只保存通用说明和无凭据配置，不保存Cookie、API密钥、个人观看历史、收藏导出或浏览器用户配置。
