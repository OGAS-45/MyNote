# MyNote

个人思维导图与知识结构记录。当前默认分支为 `graph`，保留图谱原文件、教程和不同主题的学习资料。

## 从哪里开始

- 初次使用：查看[教程文件](教程.json)，配合 [Project Graph](https://github.com/LiRenTech/project-graph) 打开。
- 技术学习：从[大模型学习](大模型学习/)或[编程体系](编程体系/)进入。
- 合并的学习记录：[学习资料](学习资料/README.md)，包含原 LLM-Notes-Chuan 与社区正文；[早期 C/C++ 练习](编程体系/早期C与CPP练习/README.md)保留最初的算法题与通过纪念。
- 日常工具：[B站主动观看工作流](工具工作流/bilibili/README.md)，包含 Gate＋无限历史记录的安装、配置和恢复步骤。
- 其他主题：按根目录中的主题文件夹查找，保留原图结构，不把所有资料强行转换成一种格式。

## 维护方式

本仓库主要保存图谱。其他载体中的笔记可以通过索引关联，不需要在这里反复复制全文。

仓库同时存在 `main` 和 `graph` 分支。2026-10-21 的文件树比较发现，`main` 仍有 12 个未出现在 `graph` 相同路径下的备份文件；两个分支中的主图 `大模型学习/大模型学习.json` 和 `知行/知行.json` 内容也不同。

这些差异只说明文件版本不同，不代表哪一份更完整。整理时先保留两个分支和原图，再按需要比较或导出，不能把默认分支视为全部资料的替代品。

个人经历相关文件需单独确认公开范围。整理目录或改善 README，不代表已经完成隐私审查。
